# 使用 jev

jev 会真的移动鼠标、按键、切换窗口。每个原语动作的后果由调用方负责。

多步目标优先用 `run_goal`，把目标用一句话交给它。要自己控制每一步时，先 `inspect_screen` 拿到 `state_id` 和元素编号，再按这个编号操作。编号只对这一次读屏有效。

- `stale_state`：先重新读屏，再用新的 `state_id`。
- `busy`：另一个调用正占着桌面。稍后重试，不要连发。
- `forbidden`：这个应用不能操作。不要设法绕过。终端、UAC、锁屏、设置、任务管理器、jev 自己，以及发起请求的宿主，都不能操作。IDE 只能点击和滚动，不能输入。

取消这次调用，或把鼠标推到屏幕左上角，都会在下一次输入前停下。

工具参数和错误种类见 [references/tools.md](references/tools.md)。
